Privacy Policy

Last updated: November 3, 2026

Generic Skyblock Bot (“the bot”) is built to collect as little as possible. This page explains what it handles and why.

What we don't store

The bot has no database. It does not save your Discord user ID, messages, server information or command history.

What the bot processes

  • Command input. When you run a command, Discord sends the bot the command, its options (such as a Minecraft username or profile name) and basic details like your user ID, so it can reply and make sure only you can use the buttons on your own reply. This is used only to answer that command.
  • Minecraft player data. To answer a command, the bot looks up the requested player's public Hypixel and Mojang data. This data is cached in memory for up to 5 minutes to avoid repeated requests, then discarded. A bot restart clears it.
  • Anonymous lookups. When you leave the name empty, the username you type into the popup is used only to fetch the stats. It is not shown in the reply and not stored. Buttons on the reply refer to the player through a random token kept in memory.
  • Error logs. If something goes wrong, technical error details may be written to the server's logs to fix the problem. These are kept briefly and not shared.

Third-party services

To answer commands, the bot contacts Discord, the Hypixel API (through our own proxy), Mojang's username services, and public sources for item prices and game data. These services have their own privacy policies.

Sharing

We don't sell, share or use your data for advertising or tracking.

Children

The bot is meant for people old enough to use Discord under Discord's own age requirements.

Your choices

Since no personal data is stored, there's nothing to delete. You can stop using the bot or remove it from your server at any time. If you have questions or concerns, open an issue on GitHub.

Changes

We may update this policy and will change the date above when we do.
